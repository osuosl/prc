PC Remote Control Card  

Uses a W5500 10M/100M network chip to expose the computer's serial port on a tcp port, which makes remote linux maintenance convenient.  
It can also control the reset and power buttons, provides one 20A voltage output, and provides chassis temperature monitoring,  
supporting up to 32 temperature probes.  
  
Input voltage 5-30V  

Serial speeds supported: 300-921600Bps

Development environment: arduino 

7 units were donated to debian's mips build machine cluster; they work well
